Free disk space from AI models
without deleting a byte

Marea is a free, open-source Windows app for people who run AI locally. It frees the space taken by Hugging Face, Ollama, ComfyUI, GGUF and safetensors models, tells you which models could run code when loaded, and rescues the ones that are disappearing from their hub.

How it works

1. Proof, not guesses

Every file is fingerprinted (SHA-256 and tensor headers). A file can leave the disk only if Marea can prove a way to get the exact bytes back: a duplicate, a bit-exact recipe, a pinned Hugging Face commit, an Ollama blob or your NAS.

2. Evaporate, don't delete

The file stays in its folder with its name and size but takes 0 bytes, using the same Windows mechanism as OneDrive “online-only” files. No admin rights, no driver of its own.

Your results, protected

Share an image of your numbers in one click, find models you have not touched in 90 days, and block programs (backups, scanners) that would undo a cleanup by reading every file.

3. Back on open, verified

When ComfyUI, Python, llama.cpp or any program opens it, Marea brings it back on the fly and re-checks its SHA-256. One click undoes any cleanup.

Every model, and whether it is safe to load

The Models page reads each file's own header: format (GGUF, safetensors, PyTorch, ONNX), quantization or precision, parameters, where it would come back from, and a calm safety verdict. Pickle files are rated by what they would import, without unpickling them; GGUF chat templates that try to escape their Jinja sandbox are flagged.

Built for scripts and AI agents

mareactl check .\downloads\new-model.ckpt --json   # exit 4 = don't load it
mareactl watch --json                              # exit 3 = models at risk
$env:MAREA_READONLY = "1"; mareactl models --json  # inventory, no changes possible

Versioned JSON schemas, documented exit codes, read-only mode, untrusted names sanitised. See AGENTS.md.

On Linux: mareactl frees space too. Install the agent once with sudo mareactl service install; freed files come back, verified, when a program opens them, and files a running model server has open are never touched.

On macOS and Linux: the safety check is also a standalone binary, marea-check, for Linux (x64, ARM) and macOS (Apple Silicon, Intel). Download it from Releases; same verdicts, JSON and exit codes.

Questions

How do I free disk space used by Hugging Face, Ollama and ComfyUI models without deleting them?

Install Marea, let it find your model folders, run a scan, then use “Free up space in 3 clicks”. Only files with a verified way back are evaporated; they come back automatically when opened, and every cleanup can be undone.

Is a .ckpt, .pt or .bin file safe to load?

Pickle-based files can run code when loaded. Marea's Models page, or mareactl check <file>, reads the file without running it and tells you: safe format, no code found, check before loading, or dangerous.

What if a model is removed from Hugging Face or Ollama?

Marea checks its sources every day and catches early signs. Files at risk are brought back while the source still answers; possible last copies are kept and copied to your NAS.

Can I lose a file?

No by design: only files with a verified source that survives the operation are evaporated, every byte that comes back is re-hashed, and unique files are never touched. Read the security model.

What does Marea send over the network?

No telemetry and never your paths or file contents. Only public repository names, public digests and an update check, each of which can be turned off. Details in the privacy policy.

Why did Ollama 0.40 double the size of my models, and how do I get the space back?

Ollama 0.40 converted some GGUF models on your PC and kept the original next to the converted copy, only so you could go back to an older Ollama; you may also see hidden llamacpp:<digest> entries. Marea finds these rollback copies and frees them without deleting them: if you ever downgrade, the original returns from the Ollama registry, verified by digest. Use the Models page or mareactl free --rollback --yes.

Does it work on macOS or Linux?

Linux: yes, since 0.8. Download mareactl for Linux, run sudo mareactl service install once, then add, scan and free as on Windows. A fanotify agent brings freed files back, verified, when a program opens them. macOS: the model safety check (marea-check) runs there; freeing space needs a signed File Provider extension and is on the roadmap.
